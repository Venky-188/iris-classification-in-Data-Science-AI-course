# Iris Flower Classification 🌸

A supervised machine learning project to classify Iris flowers into three species 
(*Setosa, Versicolor, Virginica*) based on sepal and petal measurements.

## 📘 Project Description
This project uses the classic Iris dataset and applies classification algorithms 
(Logistic Regression, KNN, Decision Tree) to predict flower species.

## 🧠 Technologies Used
- Python
- pandas, numpy, seaborn, matplotlib
- scikit-learn
- streamlit (for UI)
